### Human Review Checklist — sau khi AI sinh code:
- [ ] AI có thực hiện đúng Coding Task được giao không?
- [ ] Có thay đổi file hoặc component ngoài Coding Plan không?
- [ ] Code có tái sử dụng đúng component và service hiện có không?
- [ ] UI có xử lý đầy đủ validation, loading, success và error state không?
- [ ] UI và API có nhất quán về request, response và error handling không?
- [ ] Backend có hiện thực đúng Business Rules không?
- [ ] Business Logic có được đặt đúng layer không?
- [ ] Code có tuân thủ architecture và coding conventions hiện tại không?
- [ ] Có hard-code hoặc duplicate logic không cần thiết không?
- [ ] Có ảnh hưởng đến chức năng hiện có không?
- [ ] Có assumption nào AI tự đưa ra mà chưa được xác nhận không?
- [ ] Code có đủ rõ ràng để Developer khác tiếp tục bảo trì không?
- [ ] Coding Log có phản ánh đúng các thay đổi thực tế không?
- [ ] Task đã sẵn sàng để chuyển sang Unit Testing chưa?
